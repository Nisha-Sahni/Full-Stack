# Student Academic Portal

A React + Vite student academic portal for the academic CRUD experiment.

## Included

- Dashboard styled like the provided academic portal reference
- Students CRUD: Create, Read, Update, Delete
- REST API integration with JSONPlaceholder
- Local Storage persistence
- Academic Overview
- Academic Performance
- Quiz module inside Academic
- React Router navigation
- Responsive layout

## Run

```bash
npm install
npm run dev
```

Open the localhost address shown by Vite.
