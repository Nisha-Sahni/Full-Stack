# MITS Gwalior — Multi-Section College Website

A React + Vite frontend with React Router and an Express REST API, designed from the provided Experiment 1 screenshots for Madhav Institute of Technology & Science (MITS), Gwalior.

## Pages
- Home
- About
- Academics
- Admissions
- Placements
- Contact

## Tech
React, Vite, CSS3, React Router, Node.js, Express.js.

MongoDB can be connected later for dynamic notices. The current API includes sample notices so the project works immediately without requiring MongoDB.

## Run

### 1. Install
```bash
npm run install-all
```

### 2. Start frontend + backend
```bash
npm run dev
```

Frontend: http://localhost:5173  
Backend: http://localhost:5000

### Run separately
```bash
npm run client
npm run server
```
