TIMED MULTI-CATEGORY QUIZ + WEATHER DASHBOARD

Files:
- index.html
- style.css
- script.js

How to run:
1. Open the folder in VS Code.
2. Install/use Live Server.
3. Right-click index.html -> Open with Live Server.
4. Enter your name, select category and time.
5. Complete the quiz.
6. Search a city in the Weather Dashboard.

Technologies demonstrated:
- HTML5
- CSS3
- JavaScript ES6+
- DOM manipulation
- Event handling
- setInterval() timers
- State management
- Functions/closures concepts
- Local Storage
- Fetch API
- async/await
- Open-Meteo Geocoding and Forecast REST APIs

Note:
Weather requires an internet connection because the application calls the public Open-Meteo APIs.
